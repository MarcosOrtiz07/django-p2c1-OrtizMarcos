# EcoEnergy

Backend desarrollado con **Python y Django** como parte de un proyecto estudiantil.

## Descripción y objetivo

**EcoEnergy** es un proyecto estudiantil desarrollado utilizando Python y Django. El objetivo de este repositorio es servir como base para el desarrollo del backend del proyecto.

Actualmente, el proyecto se encuentra en una etapa inicial de configuración y desarrollo.

## Requisitos previos

Antes de comenzar, es necesario tener instalado:

* Python
* Git

## Clonación del repositorio

Clonar el repositorio utilizando Git:

```bash
git clone https://github.com/MarcosOrtiz07/django-p2c1-OrtizMarcos.git
```

Luego, ingresar a la carpeta del proyecto:

```bash
cd django-p2c1-OrtizMarcos
```

## Creación y activación del entorno virtual

Crear el entorno virtual `.venv`:

```bash
python -m venv .venv
```

Activarlo en Linux:

```bash
source .venv/bin/activate
```

Una vez activado, debería aparecer `(.venv)` al inicio de la terminal.

## Instalación de dependencias

Con el entorno virtual activado, instalar las dependencias especificadas en `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Comandos de verificación

Para comprobar que la configuración del proyecto Django es correcta, ejecutar:

```bash
python manage.py check
```

También se puede iniciar el servidor de desarrollo para comprobar que el proyecto funciona correctamente:

```bash
python manage.py runserver
```

Luego, acceder desde el navegador a la dirección indicada por Django en la terminal.

Para detener el servidor:

```bash
Ctrl + C
```
